# Подготовка к защите (неделя 4)

## 1. Главная цель и функционал
Продуктовый интернет-магазин: клиент регистрируется, ищет продукты, собирает корзину, оформляет заказ с адресом и временем доставки, оплачивает (карта / наличные / СБП) и отслеживает статус. Администратор управляет каталогом и статусами заказов.

## 3. Вопросы, которые могут задать
- **Чем композиция отличается от агрегации?** Композиция — часть не живёт без целого (OrderItem без Order); агрегация — часть независима (Product).
- **Зачем `<<include>>`?** Проверка наличия и расчёт стоимости обязательны при каждом оформлении заказа.
- **Как добавить новый способ оплаты?** Создать класс, реализующий `IPayment`; `OrderService` менять не нужно (OCP).
- **Где применён DIP?** `OrderService` принимает `IPayment` и интерфейсы репозиториев.
- **Как защищены пароли?** PBKDF2-SHA256 с солью, в открытом виде не хранятся.
- **Как запустить?** `cd Source && python main.py`; тесты — `python -m unittest discover -s tests`.

## 4. Команды Git
| Команда | Что делает |
|---|---|
| `git branch` | Показывает ветки / создаёт ветку (`git branch имя`) |
| `git checkout -b имя` / `git switch -c имя` | Создать ветку и перейти в неё |
| `git add .` | Добавить изменения в индекс |
| `git commit -m "сообщение"` | Зафиксировать изменения локально |
| `git merge имя` | Влить ветку `имя` в текущую |
| `git push origin имя` | Отправить ветку на GitHub |
| `git pull` | Получить изменения с GitHub и слить |
| `git status` / `git log --oneline` | Состояние / история |
